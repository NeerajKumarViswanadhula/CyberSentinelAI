# CyberSentinel AI
### The AI That Reconstructs Cyberattacks

CyberSentinel AI is a cybersecurity threat detection dashboard that analyzes security logs, identifies suspicious activities, reconstructs attack timelines, and recommends defensive actions.

## Features
- Security log analysis using CSV files
- Detection of repeated failed login attempts
- Identification of suspicious IP addresses
- Attack timeline reconstruction
- Threat severity alerts
- Recommended defensive actions

## Technologies Used
- Python
- HTML
- CSS
- CSV
- Python HTTP Server

## How to Run

1. Install Python 3.12 or later.
2. Open the project folder in Terminal.
3. Run:

   `python app.py`

4. Open your browser and visit:

   `http://127.0.0.1:8000`

## Project Status
Local dashboard prototype developed. AI integration with NVIDIA open-source models through Nebius Token Factory is planned.
